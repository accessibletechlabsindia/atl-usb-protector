ATL USB Protector v1.0

Enterprise-Grade USB Security for NVDA Screen Reader

Overview

The ATL USB Protector is a flagship security plugin engineered specifically by Accessible Tech Labs India for NVDA screen reader users. Designed for visually impaired professionals, students, and power users, this add-on acts as a silent, high-performance security guard for your system. It actively monitors your computer for newly connected USB drives and automatically neutralizes potential threats by safely ejecting or locking unauthorized drives, ensuring your data and privacy remain 100% secure.

Core Features & Capabilities

This initial release brings powerful, automated security features directly to your screen reader, bypassing complex Windows security settings.

1. Auto-Eject (Maximum Security)

Instantly and safely ejects any unknown or unauthorized USB drive the moment it is plugged in. The system will not even mount the drive, ensuring zero chance of malware execution or data theft.

2. Read-Only Lock (Registry-Level Protection)

Uses deep Windows Registry policies (StorageDevicePolicies) to lock unauthorized USB drives in Read-Only mode. You can safely read files from the USB, but no viruses can transfer to your system, and no one can copy your personal data onto the USB.

3. Smart Grace Period (10-Second Whitelist)

When an unknown USB is inserted, the add-on provides a smart 10-second auditory grace period. Simply press a quick shortcut key within this timeframe to instantly add the drive to your Trusted List, bypassing the need to open complex settings.

4. Trusted USB Management

Easily manage your personal USB drives. Once a drive is added to the Trusted List, it will always mount normally without any interruptions or security blocks.

5. One-Click Global Unlock

If you have locked drives in Read-Only mode, you can instantly restore all USB drives to their normal Read/Write state using the "Unlock All USB Drives" button directly from the settings menu.

6. Native NVDA Settings Integration

Features a fully accessible, dynamic GUI integrated directly into the native NVDA Preferences menu. The settings panel intelligently hides advanced options when protection is disabled, ensuring a clean and clutter-free experience.

How to Configure

  • Open NVDA Menu -> Preferences -> Settings.
  • Arrow down to the ATL USB Protector category.
  • Check the "Enable USB Protection" box.
  • Select your preferred default action for unauthorized USBs:
    • Eject: Safely removes the drive immediately.
    • Read-Only: Locks the drive to prevent data modification (requires UAC Admin approval).
    • Alert: Only provides an auditory security warning without blocking the drive.
  • Insert your personal USB drive and click "Add Current USB to Trusted" to whitelist it.
